# Security Policy

## Supported Versions

Security updates are applied to the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, report vulnerabilities privately using **GitHub Security Advisories**:

1. Navigate to the repository's **Security** tab on GitHub:
   `https://github.com/Amal-kphilip/Framelet/security/advisories/new`
2. Provide a clear description of the vulnerability, steps to reproduce, and any potential impact.
3. You should receive an acknowledgment within 72 hours, along with updates as the issue is investigated and resolved.
